# L.L.M Academy - 광주 2기

본 Repository는 L.L.M Academy 광주 2기 수강생들의 프로젝트 수행을 위한 공간입니다.

## 📌 이용 방법
1. 본 Repository 우측 상단의 `Fork` 버튼을 클릭합니다.
2. 본인의 GitHub 계정을 Owner로 선택하여 Fork를 생성합니다.
3. Fork한 개인 Repository에서 프로젝트를 진행합니다.
4. 개인 및 팀별 폴더 구성은 자유롭게 진행합니다.

## 📌 팀 프로젝트
- 팀 프로젝트는 팀원 간 협의하여 공동 작업 공간을 구성합니다.
- 필요한 경우 팀원을 Collaborator로 초대하여 함께 작업할 수 있습니다.

## ⚠️ 유의사항
- 본 Repository 및 Fork한 Repository는 Public으로 외부에 공개됩니다.
- 개인정보, 비밀번호, API Key 등 민감한 정보는 업로드하지 마세요.
- 프로젝트별 제출 및 평가 방식은 담당 강사의 안내를 따릅니다.

## 팀 주제 (12/22까지)

- **주제:** 광주 챔피언스필드 — 원정팬별 취향에 맞는 먹거리 추천 및 수요예측서비스
- **결정 문장:** 우리 팀은 광주 기아챔피언스필드 주변(임동·신안동 도보권)에서 원정팬에게 응원팀 취향에 맞는 가게·메뉴를 추천하고, 챔필 주변 음식점·카페의 원정팀별 경기일 수요를 예측하는 서비스를 만든다.

| 팀원 | 자산 유형 | 내 질문 | 오늘 모을 소스 |
|---|---|---|---|
| 박홍 | 산업 | 경기 전후 원정팬은 챔필 주변 어떤 식당·메뉴를 찾나? 경기일에 포장·간식 수요는 어느 가게로 몰리나? | 네이버 블로그 — 챔필 주변 식당 직관 후기, 카페·떡집·포장 후기 (창억떡·인크커피 등) |
| 정주예 | 커뮤니티 | 원정팬들이 좋아하는 광주 먹거리나 맛집이 어디인가? | 블로그, 팬카페 |
| 홍경석 | 산업 | 경기일에 주변 상권(광주 임동)은 언제 바쁘고 어떻게 돌아가나? | 공공데이터포털, 누리집 사진 + 직접촬영 |
| 이재석 | 산업 | 일정, 날씨, 원정팀, 예매율 등의 지표와 주변 가게 매출의 상관관계를 파악할 수 있나? | KBO, 기상청, 카카오맵, 네이버 지도 등 |
