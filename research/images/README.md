# 대표 사진 폴더

`scripts/make_summary_pdf.py`가 이 폴더의 사진을 `research/종합.pdf`에 넣는다.
아래 파일 이름으로 사진(jpg, png)을 넣고 스크립트를 다시 실행한다.

| 파일 이름 | 가게 · 숙소 |
|---|---|
| r1 | 시골집 |
| r2 | 왕뼈사랑 유스퀘어 |
| r3 | 월드밥 |
| c1 | 라이크 마이 베이커리 유스퀘어 |
| c2 | 육각커피 신세계백화점광주점 |
| c3 | 마리앤마르코 |
| h1 | 에이치원호텔 |
| h2 | 브라운도트호텔 신안점 |
| h3 | 소풍호텔 |
| h4 | 광주 에디션호텔 |
| h5 | 비지니스호텔 어반라이프 |

```bash
python scripts/make_summary_pdf.py
```

사진은 직접 찍었거나 사용 허락을 받은 것만 넣는다.
